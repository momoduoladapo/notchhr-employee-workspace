REDESIGN THE NOTCHHR AUTHENTICATION WALKTHROUGH — PRODUCT PREVIEW FIRST

The current authentication walkthrough design is NOT acceptable.

Do not redesign the entire authentication page from scratch. Keep the existing overall split-screen authentication structure, branding, typography direction, navigation, and login panel, but completely rethink the LEFT-SIDE WALKTHROUGH VISUALS.

The purpose of the walkthrough is to show users what they will actually experience inside their Employee Workspace.

IMPORTANT:
This is a PRODUCT WALKTHROUGH, not an abstract marketing illustration.

The visual on each slide must be directly derived from the REAL WORKSPACE UI and its actual cards/components.

==================================================
CORE VISUAL PRINCIPLE
==================================================

Every walkthrough slide should contain:

1. A short editorial headline.
2. A concise supporting description.
3. A large visual showcase area.
4. Inside that showcase area, use REAL UI CARDS extracted from / recreated from the actual Employee Workspace.
5. The UI cards must remain recognizable as actual NotchHR workspace components.
6. Add subtle contextual illustration/background treatment BEHIND the cards where useful.
7. The illustration must support the story, not replace the product UI.

DO NOT use generic abstract circles, random geometric blocks, floating rectangles, decorative lines, or meaningless shapes as the primary visual.

The actual workspace card is the hero.

==================================================
IMPORTANT: USE THE ACTUAL WORKSPACE CARDS
==================================================

When a slide talks about a specific feature, take the corresponding card/component from the Employee Workspace and display that exact UI concept inside the walkthrough.

Examples:

"Your dashboard, your way"
→ Show the actual Attendance Today card and Quick Actions card from the workspace.

"Your data stays private"
→ Show the actual Employee Benefits / Payslip card from the workspace.

"Drag, drop, done"
→ Show the actual workspace cards inside an edit-mode composition, demonstrating that cards can be rearranged.

"Never miss what matters"
→ Show the actual Announcements card from the workspace.

"Everything in one workspace"
→ Show a curated composition of actual workspace modules/cards.

Do not invent replacement cards that merely resemble the workspace.

The visual language, spacing, typography, labels, icons, values, borders and hierarchy should feel like they belong to the exact same product.

==================================================
CARD PRESENTATION
==================================================

The workspace cards should NOT simply float alone on a blank background.

Create a sophisticated product-illustration composition around them.

For example:

- Use a subtle tinted/lavender environment behind the card.
- Use soft oversized masks or cropped photography/employee imagery where appropriate.
- Use subtle depth and shadows.
- Allow the actual UI card to sit clearly in front of the supporting visual.
- Use partial cropping where appropriate to make the product feel larger.
- Use one dominant card with one or two supporting cards rather than many tiny cards.
- Cards should be large enough that their content can actually be understood.

Think:

REAL PRODUCT UI + EDITORIAL ART DIRECTION

not:

ABSTRACT SHAPES + TINY UI MOCKUP.

==================================================
PHOTOGRAPHY / ILLUSTRATION
==================================================

Where a slide benefits from an illustration or employee image, use it as a contextual background or visual mask.

For example:

- Employee photograph partially masked behind the workspace card.
- Subtle portrait silhouette behind an Employee Directory card.
- Workplace/environment photography behind an Attendance card.
- Soft abstract illustration behind a privacy/payroll card.

The image should occupy the visual environment.

The actual UI card should sit on top of it.

Do NOT place a tiny card in the middle of a giant empty gradient panel.

Do NOT use generic decorative circles as the main visual.

IMPLEMENTATION RULE
==================================================

Do not create disconnected duplicate UI components if the corresponding workspace component already exists.

Reuse the existing workspace card/component structure wherever possible.

The walkthrough should reference the same visual system and data structures as the Employee Workspace so that if a card's design changes later, the walkthrough representation can remain consistent.

Maintain responsive behaviour.

At desktop width, cards should be large and readable.

At smaller widths, intelligently reduce the number of visible supporting cards rather than shrinking every card until its content becomes unreadable.

Never allow card content to become cramped merely to preserve the composition.
