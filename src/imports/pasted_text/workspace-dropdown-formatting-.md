# Refine Workspace Management Dropdown Formatting

Keep the current Workspace Management functionality and overall design direction.

Do not redesign the Employee Workspace.

Do not change:

- Workspace dropdown trigger
- Existing workspace names
- Workspace selection behaviour
- Create New Workspace
- Customize Layout
- Rename functionality
- Delete functionality
- Existing colours
- Typography
- Icons
- Existing workspace data

Only improve the formatting, spacing, alignment and usability of the Workspace Management dropdown.

---

## Selected Workspace Edit State

When a workspace is selected and its edit controls are revealed:

- Keep the workspace name input clearly separated from the Rename and Delete actions.
- Do not place the action buttons directly against the input.
- Add intentional vertical spacing between the editable workspace row and the action row.
- Ensure the edit controls feel like a separate secondary action area.

The workspace name input should remain the primary focus.

Rename and Delete should appear below the input as secondary actions, not as elements attached to the input.

---

## Spacing

Apply consistent spacing throughout the dropdown.

Use clear spacing between:

1. The **WORKSPACES** heading and the first workspace item.
2. Each workspace item.
3. The selected workspace input and its action controls.
4. The Rename/Delete action row and the next workspace item.
5. The workspace list and the bottom utility actions.

Do not allow controls to touch or visually crowd one another.

The dropdown should feel calm, organised and easy to scan.

---

## Rename and Delete Actions

Place Rename and Delete inside a dedicated action row below the selected workspace name.

The action row must have sufficient top spacing from the input.

Use consistent button height and padding.

The actions should be visually balanced:

- **Rename** should be a neutral secondary action.
- **Delete** should use a subtle destructive treatment.
- Delete should not visually dominate the workspace dropdown.
- Keep both actions easy to click or tap.

Do not place Rename and Delete too close to the input border.

Do not make the buttons appear attached to the input.

---

## Close/Cancel Icon

If an **X** icon is used to close the edit state:

- Place it in a clear, consistent position.
- Give it its own touch/click target.
- Keep it visually separate from Rename and Delete.
- Align it properly with the edit state.
- Do not allow it to appear cramped against the action buttons.

Clicking the X should exit the edit state without changing the workspace name.

---

## Workspace Item Alignment

Ensure all workspace items have:

- Consistent left padding.
- Consistent right padding.
- Consistent row height.
- Proper vertical alignment.
- Equal spacing between items.

The workspace names should align on the same left edge.

The pen icons should align consistently on the right edge.

Long workspace names and timestamps must not collide with the pen icon.

Use text truncation where necessary while preserving the workspace identity.

---

## Selected Workspace

The active workspace should remain clearly visible.

Maintain the existing selected-state styling.

Ensure:

- The check icon is properly aligned.
- The workspace name is vertically centred.
- The selected background has consistent internal padding.
- The edit pen is aligned correctly.
- The selected row does not feel crowded.

Do not increase the selected row height unnecessarily.

---

## Dropdown Sections

Maintain a clear hierarchy:

**WORKSPACES**

Workspace list

Divider

**Customize Layout**

**+ Create New Workspace**

The bottom actions should remain visually separated from the workspace list.

Use consistent divider spacing.

Do not allow the bottom actions to feel attached to the last workspace item.

---

## Dropdown Size

Keep the dropdown compact but give the content enough room.

Do not make it excessively tall or wide.

Increase the dropdown height only if needed to provide proper spacing and prevent crowded controls.

Ensure all content remains visible without clipping.

---

## Responsive Behaviour

Maintain the same formatting quality on:

- Desktop — 1440px
- Tablet — 768px
- Mobile

The dropdown must:

- Stay within the viewport.
- Avoid horizontal overflow.
- Keep all action buttons accessible.
- Maintain comfortable touch targets.
- Preserve spacing when workspace names are long.

Do not allow the Rename, Delete or close controls to overlap or become clipped.

---

## Final Validation

Before completing the update, verify:

✓ The workspace name input has clear spacing around it.

✓ Rename and Delete are visually separated from the input.

✓ Rename and Delete sit in a dedicated action row.

✓ The action controls are not crowded.

✓ The close icon has its own clear position.

✓ Workspace names align consistently.

✓ Pen icons align consistently.

✓ Long workspace names do not collide with controls.

✓ The dropdown remains compact and easy to scan.

✓ No functionality has been changed.

✓ No Employee Workspace content has been redesigned.

This is a formatting and usability refinement only.
