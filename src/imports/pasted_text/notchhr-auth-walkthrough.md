REWORK THE NOTCHHR AUTHENTICATION WALKTHROUGH

Use the current authentication design and the existing Employee Workspace already built in this project.

The overall visual direction should follow the latest approved authentication concept:

- Desktop web
- Split-screen layout
- Smart lavender workplace pane on the left
- Clean white authentication area on the right
- Premium NotchHR SaaS aesthetic
- Time/date/weather as subtle contextual information
- Organization announcements at the bottom
- Manual walkthrough navigation
- NO AUTOPLAY

==================================================
1. THE MOST IMPORTANT CHANGE
==================================================

The walkthrough images must NOT be newly designed illustrations or generic product mockups.

Instead:

**USE THE ACTUAL EMPLOYEE WORKSPACE UI THAT ALREADY EXISTS IN THIS PROJECT.**

The walkthrough should visually demonstrate the real Employee Workspace.

For each walkthrough slide:

1. Identify the topic being explained by that slide.
2. Find the corresponding card/module/section in the existing Employee Workspace.
3. Extract/use that exact UI section from the existing workspace.
4. Display that actual workspace UI as the visual for the walkthrough slide.

The authentication walkthrough should therefore feel like a preview of the real workspace the employee is about to enter.

- Do not create a separate mobile-app visual.
