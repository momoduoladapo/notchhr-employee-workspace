# NOTCHHR REWIND — WORKSPACE EXPERIENCE

Design and implement **NotchHR Rewind** as a shared experience available in **both the Admin Workspace and Employee Workspace**.

This is an existing NotchHR feature/content experience. Do not reinterpret, rewrite, summarize, expand, or invent any of its content.

## 1. REWIND REMINDER CARD

Add a small floating **NotchHR Rewind reminder card** fixed to the **bottom-right corner of the screen**.

### Position

* Fixed to the bottom-right of the viewport.
* It must remain visible above the workspace content.
* Do not place it inside the page layout.
* It should not push, resize, or reflow the workspace.
* Maintain a comfortable distance from the bottom and right edges.

### Behaviour

The reminder must behave exactly as follows:

1. The Rewind reminder appears automatically.
2. The user can close/dismiss the reminder.
3. When dismissed, it disappears completely.
4. After exactly **240 seconds (4 minutes)**, the reminder automatically appears again.
5. This 240-second reappearance cycle continues.
6. If the user clicks the reminder instead of closing it, open the full **NotchHR Rewind experience inside a modal**.
7. Opening the Rewind modal should stop the reminder from obstructing the user.
8. The reminder should remain dismissible.
9. Do not make the reminder permanently disappear after one dismissal.

### Reminder Design

Create a compact, premium NotchHR notification/card that feels like part of the existing workspace design system.

Use:

* NotchHR brand language
* Poppins typography
* Existing NotchHR purple **#440F7C**
* Existing NotchHR magenta **#D62196**
* White surfaces
* Rounded corners
* Subtle elevation
* Clean spacing
* Premium SaaS styling

Do not introduce unrelated colors.

The reminder should clearly communicate that it is the user's **2025 NotchHR Rewind** and invite the user to open it.

Do not invent additional Rewind statistics, claims, or content.

---

# 2. REWIND MODAL

When the user clicks the reminder card, open **NotchHR Rewind in a large modal overlay**.

The modal should feel like a premium year-in-review experience rather than a normal settings dialog.

### Modal requirements

* Large desktop-friendly modal.
* Centered within the viewport.
* Background workspace should remain visible behind the modal with an appropriate overlay.
* Rounded corners.
* Clean spacing.
* Strong visual hierarchy.
* Poppins typography.
* Use the existing NotchHR visual language.
* Make the experience responsive for desktop, tablet, and mobile.
* Include a clear close control.
* Closing the modal returns the user to the workspace.
* Do not navigate the user away from the workspace.

The Rewind content should be presented as a **scrollable/slide-based storytelling experience** inside the modal.

Use the supplied images as the visual assets for their corresponding sections.
