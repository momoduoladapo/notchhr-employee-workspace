REWORK THE EXISTING NOTCHHR DESKTOP AUTHENTICATION EXPERIENCE

Do not create a new authentication concept. Rework the current design based on the existing implementation and make the overall composition feel more polished, intentional and premium.

The current design is clean, but the left side feels too empty and the walkthrough feels like content placed in the middle of a large blank area.

The goal is to create a stronger visual hierarchy without adding unnecessary UI.

==================================================
1. DESKTOP COMPOSITION
==================================================

Maintain the two-column desktop layout:

LEFT — Workplace Welcome / Walkthrough
RIGHT — Authentication

Keep the overall split approximately 50/50, but use the available space more intelligently.

The result should feel like:

"Premium workplace welcome experience + focused authentication"

NOT:

"Dashboard + login screen"

==================================================
2. LEFT SIDE — MAKE THE WALKTHROUGH THE HERO
==================================================

The existing employee walkthrough is already designed in this project.

USE THAT EXISTING WALKTHROUGH.

Do not:
- Create new walkthrough content
- Rewrite the walkthrough
- Replace the walkthrough
- Invent new illustrations
- Add new product features
- Change the existing walkthrough messaging

Instead, improve how the existing walkthrough is presented.

The walkthrough should become the dominant visual element of the left pane.

Give it significantly more visual presence.

Use the available vertical space intentionally so the walkthrough does not appear to be floating in the middle of a large empty panel.

Create a stronger composition using:

- Typography scale
- Content positioning
- Spacing
- Visual hierarchy
- Existing walkthrough artwork/content
- Balanced whitespace

Do not fill empty space with unnecessary UI.

==================================================
3. WALKTHROUGH NAVIGATION
==================================================

The walkthrough must NOT autoplay.

The employee controls the walkthrough.

Provide:

- Previous control
- Next control
- Slide indicators
- Current slide indicator

Navigation should feel integrated into the walkthrough rather than appearing as unrelated controls.

Keep the interaction subtle and elegant.

Do not automatically change slides.

Do not automatically rotate the walkthrough.

==================================================
4. TOP OF LEFT PANE
==================================================

Keep the NotchHR logo at the top.

Keep the current time, date and timezone.

Keep weather information.

However, make these elements quiet and lightweight.

They should not look like dashboard widgets.

For example:

10:54 AM
Thu, Aug 13 · GMT+1

☁ 25°C · Patchy rain nearby · Wuse

Treat this as contextual information rather than a collection of cards.

Do not create separate large cards for time and weather.

==================================================
5. ORGANIZATION ANNOUNCEMENTS
==================================================

Keep organization announcements.

However, keep them subtle.

Place them near the bottom of the left pane as a compact workplace information area.

Example:

FROM YOUR ORGANISATION

🎉 Annual Company Retreat
August 20–22 · All Staff

If multiple announcements exist, allow manual navigation.

Do not autoplay announcements.

Do not make announcements another major card competing with the walkthrough.

==================================================
6. REMOVE THE CURRENT SENSE OF EMPTY SPACE
==================================================

Do not simply move the existing elements around.

Recompose the left pane.

The current problem is not that there aren't enough elements.

The problem is that the hierarchy is weak.

Use the existing walkthrough as the main visual anchor.

The approximate hierarchy should be:

1. Walkthrough
2. Supporting walkthrough navigation
3. Time/date/weather
4. Organization announcement

The walkthrough should clearly receive the most attention.

==================================================
7. RIGHT SIDE — AUTHENTICATION
==================================================

Keep the authentication experience clean and focused.

Do not redesign the authentication logic.

The existing flow remains:

Phone Number
→ 4-Digit PIN
→ OTP Verification
→ Employee Workspace

PIN recovery remains:

Forgot PIN
→ Phone Number
→ OTP Verification
→ Create New PIN
→ Confirm PIN
→ Success

Do not add:
- Email login
- Password login
- Social login
- Marketing content
- Pricing
- Upgrade prompts

The right side should feel calm, trustworthy and premium.

The authentication form should have a stronger visual anchor, but do not turn it into an unnecessarily large dashboard-style card.

==================================================
8. VISUAL DIRECTION
==================================================

Use the existing NotchHR visual language and the uploaded reference image as the aesthetic direction.

Maintain:

- Premium SaaS feel
- Soft lavender/purple environment
- White authentication surface
- Strong typography
- Generous whitespace
- Refined rounded corners
- Subtle borders
- Subtle shadows
- NotchHR purple and magenta accents

Avoid:

- Heavy gradients
- Excessive decorative shapes
- Glassmorphism
- Large generic illustrations
- Excessive cards
- Dashboard-style widgets
- Excessive pills
- Excessive empty space
- Unnecessary animation

The design should feel sophisticated through composition, not decoration.

==================================================
9. RESPONSIVE
==================================================

The experience must remain fully responsive.

Desktop is the primary design.

At desktop:

LEFT: Walkthrough / workplace welcome
RIGHT: Authentication

At tablet and smaller web widths:

- Adapt the proportions naturally.
- Prevent the authentication form from becoming cramped.
- Maintain the walkthrough.
- Collapse the two-column composition when necessary.

At mobile web widths:

- Use a single-column layout.
- Prioritize authentication.
- Keep the walkthrough available.
- Do not create a separate mobile-app design.
- Preserve the same visual language and experience.

No horizontal scrolling.
No clipped content.
No overlapping elements.

==================================================
10. IMPORTANT — DO NOT ADD MORE THINGS
==================================================

Do not respond to the empty space by adding more widgets.

Do not add:
- News
- More weather information
- Extra statistics
- Additional announcements
- Promotional content
- Extra cards
- Decorative dashboards

The solution is better composition, not more content.

==================================================
FINAL OBJECTIVE
==================================================

Make the authentication experience feel like a deliberate entrance into the NotchHR Employee Workspace.

The left side should communicate:

"This is your workplace."

The right side should communicate:

"Sign in to enter."

The existing walkthrough remains the hero of the left pane.

The employee manually controls the walkthrough.

NO AUTOPLAY.

Keep the design clean, spacious, premium and visually balanced.
