# REWORK NOTCHHR DESKTOP AUTHENTICATION — SMART LEFT PANE

Review the current authentication design and rework it.

The current left pane has become too busy and feels like a dashboard placed beside a login screen.

We need a much more refined and intentional experience.

## IMPORTANT — REMOVE AUTOPLAY

The walkthrough must NOT autoplay.

Do not automatically advance slides.

The employee must control the walkthrough manually.

Use:
- Previous button
- Next button
- Slide indicators

The user should be able to move through the existing walkthrough at their own pace.

Do not add automatic transitions between slides.

---

# KEEP THE EXISTING WALKTHROUGH

Use ONLY the walkthrough that has already been designed in this project.

Do not create new walkthrough content.

Do not rewrite the walkthrough.

Do not redesign its illustrations.

Do not invent additional product features.

The existing walkthrough should remain the primary visual/content experience of the left pane.

However, redesign its presentation so that it feels much more sophisticated.

---

# NEW LEFT-PANE CONCEPT

The left side should NOT look like a dashboard.

It should feel like a:

**Smart workplace welcome experience**

Think:

"Before you sign in, here's a calm glimpse of your workplace."

The walkthrough should be the hero.

Everything else should support it.

---

# LEFT PANE STRUCTURE

Use this hierarchy:

### TOP

NotchHR logo on the left.

On the right of this same area, show compact utility information:

**10:49 AM**
Thu, Aug 13
GMT+1

Beside or underneath it, show a very compact weather indication:

☁ 25°C · Patchy rain nearby
Wuse

Do NOT put the weather inside a large card.

Do NOT create separate weather and clock cards.

They should feel like lightweight contextual information.

---

# MIDDLE — WALKTHROUGH HERO

Give the existing walkthrough the majority of the available space.

This is the main reason the left pane exists.

Create a strong visual hierarchy:

Small slide indicator:

04 / 05

Large walkthrough heading:

Drag, drop,
done

Existing supporting text.

Existing walkthrough content.

Use the existing walkthrough exactly as already designed.

Make the content breathe.

Do not force unnecessary UI elements around it.

---

# WALKTHROUGH NAVIGATION

Place navigation naturally near the walkthrough content.

For example:

←     ● ● ● ● ○     →

The navigation should feel elegant and integrated into the composition.

Do not make the navigation oversized.

Do not autoplay.

Do not rotate automatically.

The employee decides when to move to the next walkthrough.

---

# ORGANIZATION ANNOUNCEMENTS

Keep organization announcements, but make them much more subtle.

Do NOT create another large dashboard-style card.

Use a small section near the bottom of the left pane:

FROM YOUR ORGANIZATION

🏆 Employee of the Month Nominations

Submit your nominations by August 18

Keep this compact.

If there are multiple announcements, allow the employee to manually navigate them.

Do not autoplay the announcements either.

Use small indicators or arrows if necessary.

The announcement should feel like a useful workplace notice, not another major component competing with the walkthrough.

---

# REMOVE THE CURRENT VISUAL BUSYNESS

The current design contains too many competing elements.

Reduce the visual noise.

Specifically avoid:

- Large weather cards
- Large announcement cards
- Multiple competing cards
- Excessive pills
- Excessive borders
- Large decorative waves
- Dashboard-like widget styling
- Excessive empty vertical areas
- Excessive controls
- Autoplay
- Heavy gradients
- Overly decorative backgrounds

The left pane should feel editorial and composed rather than like a dashboard.

---

# BACKGROUND

Keep the soft NotchHR lavender/purple atmosphere.

However, make it much more subtle.

Use the background to create depth rather than decoration.

A very subtle tonal background is acceptable.

Avoid large visible decorative shapes that compete with the walkthrough.

---

# RIGHT SIDE

Keep the authentication experience on the right.

The right side should remain extremely clean.

The flow remains:

Phone Number
→ 4-digit PIN
→ OTP Verification
→ Employee Workspace

PIN recovery remains:

Forgot PIN
→ Phone Number
→ OTP
→ New PIN
→ Confirm PIN
→ Success

Do not change the authentication logic.
