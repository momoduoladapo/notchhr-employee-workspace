# EMPLOYEE WORKSPACE — PLAN-AWARE FLUID CARD WIDTH AND PROFESSIONAL GRID REFINEMENT

IMPORTANT:

Do not redesign the Employee Workspace.

Do not change the approved visual design, colours, typography, card styling, content, Workspace Management structure, or existing functionality.

This is a workspace layout and card-sizing refinement only.

Apply this refinement across:

- HR Basic and Payroll
- HR Standard
- HR Premium

Do not use one fixed card-width layout for every plan.

Each plan must be evaluated and arranged independently based on:

- The modules available in that plan
- The number of cards displayed
- The amount and type of information inside each card
- The content density of each card
- The available workspace width
- The importance and hierarchy of each card

---

# 1. PLAN-AWARE CARD WIDTH SYSTEM

Do not force module cards to have identical widths across all plans.

A card may have a different width in:

- HR Basic and Payroll
- HR Standard
- HR Premium

This is expected and acceptable.

The width of a card should be determined by:

1. Its content requirements
2. Its information density
3. Its role and importance
4. The other cards available in that plan
5. The available space in its row

Do not preserve the same width merely for visual consistency if that width causes:

- Compressed content
- Excessive text wrapping
- Cramped tables
- Crowded tabs
- Unreadable data
- Unnecessary empty space

---

# 2. PROFESSIONAL CONTENT-HUGGING CARD BEHAVIOUR

Cards should professionally hug their content.

This does not mean every card should shrink to the smallest possible width.

It means:

- A card should not be wider than its content reasonably requires.
- A card should not be narrower than its content requires.
- A card should have comfortable internal padding.
- A card should have enough width for clear scanning.
- A card should not contain excessive unused horizontal space.
- A card should not feel stretched simply to fill a row.
- A card should not be compressed merely to fit more cards into a row.

Use appropriate:

- Minimum widths
- Preferred widths
- Maximum widths
- Flexible grid allocation
- Content-aware grid spans

The final result should feel intentional, balanced, compact, and enterprise-ready.

# 7. CARD WIDTH CLASSIFICATION

Audit all visible module cards and classify them by their actual content needs.

Use the following behaviour as guidance:

## Compact Cards

Use controlled smaller widths for cards with:

- Short summaries
- Few values
- Simple actions
- Minimal content

These cards should remain compact and should not be stretched unnecessarily.

## Standard Cards

Use balanced widths for cards with:

- Moderate information
- Multiple labels
- Small lists
- Standard actions

These cards should have enough room for comfortable scanning without taking excessive space.

## Wide Data Cards

Use wider allocations for cards with:

- Tabs
- Tables
- Employee lists
- Multiple metrics
- Detailed information
- Long labels
- Dense data
- Multiple actions

Examples may include:

- Payroll
- Employee Directory
- Employee / Identity
- Performance
- Learning

Do not automatically make all cards in these categories wide.

Inspect their actual content in the current plan and assign width appropriately.

---

# 8. FLUID GRID RULES

Use a controlled fluid grid.

The grid should:

- Use available horizontal space efficiently.
- Reflow cards when modules are unavailable.
- Reflow cards when modules are shown or hidden.
- Reflow cards after drag-and-drop.
- Reflow cards after Reset Workspace.
- Reflow cards when switching workspaces.
- Maintain consistent gaps.
- Keep rows visually balanced.
- Avoid unnecessary empty spaces.
- Avoid scattered card placement.
- Avoid rigid fixed-width columns.

Use suitable minimum and maximum widths for each card type.

Do not use one global minimum width for every card.

Do not use one global maximum width for every card.

Use card-specific sizing based on content requirements.

---

# 9. NO UNNECESSARY WIDTH

Audit every visible card for unnecessary horizontal space.

If a card has excessive empty width:

- Reduce its width where doing so does not affect readability.
- Allow another card in the row to use the recovered space.
- Do not leave unused space unnecessarily.
- Do not stretch a low-content card simply to fill a row.

If a card is too narrow:

- Increase its width where needed.
- Reduce a nearby low-content card only when safe.
- Do not compress important information.

The row should feel balanced as a complete composition.

Do not optimise cards in isolation while making the overall row look uneven.

---

# 10. ROW COMPOSITION

For every plan, inspect each row as a complete layout.

Each row should:

- Have a clear visual balance.
- Use the available width efficiently.
- Avoid one oversized card beside several cramped cards.
- Avoid multiple stretched cards with empty content.
- Avoid large unused areas.
- Avoid unnecessary additional rows.
- Maintain consistent spacing.
- Align card edges cleanly.

Do not force every row to contain the same number of cards.

The number of cards per row should be determined by:

- Card content
- Card width requirements
- Available workspace width
- The current plan

A row may contain:

- Two wider cards
- Three balanced cards
- Four compact cards

Choose the arrangement that best fits the actual cards.
