# EMPLOYEE WORKSPACE — PLAN-AWARE QUICK ACTIONS & MOBILE CHAT CORRECTION

IMPORTANT:

Do not redesign the Employee Workspace.

Do not change the approved visual design, card styling, typography, colours, workspace layout, card widths, Workspace Management, or existing functionality.

This is a focused correction to:

1. Team member chat behaviour
2. Quick Actions across HR Basic and Payroll, HR Standard, and HR Premium

---

# 1. CHAT IS A MOBILE-APP FEATURE

Chat is accessed through the NotchHR mobile application.

Do not create or open a web-based chat experience from the Employee Workspace.

Do not add a web Chat page.

Do not add an in-browser messaging interface.

Do not add “Open Chat” as a Quick Action.

Do not include Chat in the Employee Workspace Quick Actions card.

---

# 2. TEAM MEMBER CHAT ICON

Keep the chat icon on each team member in the Team card.

The chat icon should act as a mobile-app chat entry point.

When the user clicks or taps a team member’s chat icon:

- Direct the user to the NotchHR mobile app chat experience.
- Where supported, open or prepare a direct conversation with the selected team member.
- If the mobile app cannot be opened from the current device, show a clear and lightweight mobile-app handoff.
- Do not create a web chat interface.
- Do not open a generic web Chat page.

Keep the Team card design unchanged.

Do not change:

- Team member names
- Roles
- Avatars
- Online indicators
- Birthday badges
- On Leave badges

The chat icon should remain compact and aligned at the right side of each team-member row.

---

# 3. REMOVE “VIEW PAYSLIP” FROM QUICK ACTIONS

Remove **View Payslip** from Quick Actions across all plans.

Employees cannot view payslips directly from the Employee Workspace.

Do not replace it with:

- Download Payslip
- Open Payslip
- Payroll History
- Any other web-based payslip action

The Payroll card already provides the approved guidance for accessing payslips through the NotchHR mobile app.

Keep that Payroll card guidance unchanged.

---

# 4. QUICK ACTIONS MUST BE GENERATED FROM THE ACTIVE PLAN

Quick Actions must be tailored to the employee’s active licence plan.

Do not use one identical Quick Actions list across all plans.

Do not add actions simply to fill the Quick Actions card.

Do not show actions for modules that are unavailable in the employee’s plan.

Do not show:

- Upgrade
- Upgrade Plan
- Unlock Feature
- View Plans
- Locked actions
- Disabled actions for unavailable modules

Only display actions that:

1. Belong to the employee’s active plan.
2. Are available to the employee.
3. Have a meaningful employee-facing action.
4. Can open an existing workflow or module.
5. Are relevant to the logged-in employee.

---

# 5. HR BASIC AND PAYROLL — QUICK ACTIONS

Use only actions supported by the approved HR Basic and Payroll plan.

Review the existing approved modules for this plan and select the most useful employee-facing actions.

Prioritize actions such as:

- Create Requisition
- View Employee Profile
- View Announcements
- Start or submit an approval-related action when applicable

Do not include:

- Open Chat
- View Payslip
- Upgrade-related actions
- Actions from unavailable HR Standard or HR Premium modules

Do not add an action unless it maps to an approved HR Basic and Payroll module.

---

# 6. HR STANDARD — QUICK ACTIONS

Use only actions supported by the approved HR Standard plan.

Review the approved HR Standard modules and select the most useful employee-facing actions.

Prioritize relevant actions such as:

- Create Requisition
- Request Leave
- Upload Document
- Submit a Grievance, where applicable

Do not include:

- Open Chat
- View Payslip
- Upgrade-related actions
- HR Premium-only actions

Only show actions that map to available HR Standard modules.

---

# 7. HR PREMIUM — QUICK ACTIONS

Use only actions supported by the approved HR Premium plan.

Review the approved HR Premium modules and select the most useful employee-facing actions.

Prioritize relevant actions such as:

- Create Requisition
- Request Leave
- Continue Learning
- View Performance, where relevant

Do not include:

- Open Chat
- View Payslip
- Upgrade-related actions
- Actions that are unavailable to the employee

Only show Learning or Performance actions when the employee has relevant assigned or active information.

If there is no active learning or performance information, use another relevant action from an available HR Premium module.

Do not show a misleading action for an empty module.

---

# 8. CONTEXTUAL ACTION RULES

Quick Actions should respond to the employee’s actual context.

Examples:

- Show **Request Leave** when Leave is available.
- Show **Upload Document** when Document Management is available.
- Show **Continue Learning** when the employee has assigned or active learning.
- Show **View Performance** when the employee has an active performance cycle.
- Show **Submit a Grievance** when the employee can use the Grievance and Disciplinary module.
- Show **Create Requisition** when Requisition is available.

Do not show actions for modules that are:

- Unavailable in the plan
- Not enabled for the employee
- Not relevant to the employee
- Empty with no meaningful action

---

# 9. QUICK ACTIONS CARD

Keep the approved Quick Actions card design.

Do not redesign the card.

Do not change:

- Card styling
- Icon treatment
- Typography
- Colour system
- Workspace position

Ensure actions:

- Are clearly labelled.
- Use appropriate icons.
- Have comfortable touch targets.
- Are easy to scan.
- Do not overflow.
- Remain balanced even when plans have different actions.

The number of Quick Actions does not have to be identical across plans.

Do not add unnecessary actions just to make every plan have the same number.

---

# 10. FINAL VALIDATION

Before completing, verify:

## Chat

- Team members retain the chat icon.
- The chat icon is a mobile-app handoff.
- No web chat interface was created.
- No web Chat page opens.
- Chat is not included in Quick Actions.

## HR Basic and Payroll

- Quick Actions come only from approved HR Basic and Payroll modules.
- No unavailable actions appear.
- No View Payslip appears.
- No Open Chat appears.
- No upgrade action appears.

## HR Standard

- Quick Actions come only from approved HR Standard modules.
- No HR Premium-only action appears.
- No View Payslip appears.
- No Open Chat appears.
- No upgrade action appears.

## HR Premium

- Quick Actions come only from approved HR Premium modules.
- Learning and Performance actions are contextual.
- No View Payslip appears.
- No Open Chat appears.
- No upgrade action appears.

# FINAL PROTECTION RULE

Do not redesign the Employee Workspace.

Do not change unrelated cards.

Do not create web chat.

Only:

1. Keep Team chat as a mobile-app handoff.
2. Remove Chat from Quick Actions.
3. Remove View Payslip from Quick Actions.
4. Generate Quick Actions from the employee’s active plan and relevant employee context.
5. Never display unavailable, locked, or upgrade-related actions.
